Event-driven automation for Uyuni (GSoC 2026, openSUSE)

April 2026 - August 2026

An MQTT event publisher in Uyuni's Java core, a documented topic scheme, and a Node-RED node package so automations can be wired up visually. Around 175 hours of work in a global open-source codebase, mentored by Ondrej Holecek and Abid Mehmood. Read the write-up on openSUSE News.

Argus, attendance that resists proxy attendance

September 2026 - present

Students scan a classroom QR code that rotates every three seconds; the phone signs each scan with a hardware-backed key bound to that student. Fastify and PostgreSQL on the backend, a React console for staff, and a Flutter student app. Live site · Source.

Doorman, a Wi-Fi bridge for devices that cannot sign themselves in

August 2026

Smart bulbs, speakers and consoles have no browser, so they can never clear a captive portal. Doorman turns an ESP32 into a NAT bridge that handles the login, including WPA2-Enterprise, and hands those devices a plain WPA2-PSK network. Source.
