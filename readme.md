# geetanshgoyal.in

This is the repository for my 3D developer portfolio website <a href="https://geetanshgoyal.in/"><samp>geetanshgoyal.in</samp></a> 🚀. It features an interactive 3D room with a computer workstation running a customized RetroOS 2D desktop interface. Thanks for taking the time to check this out. If you have any questions or comments, feel free to shoot me an email at <samp><a href="mailto:goyalgeetansh@gmail.com">goyalgeetansh@gmail.com</a></samp> or connect with me on GitHub/LinkedIn!

To setup a dev environment:

```bash
# Clone the repository

# Install dependencies 
npm i

# Run the local dev server
npm run dev
```

To serve a production build:

```bash
# Install dependencies if not already done - 'npi i'

# Build for production
npm run build

# Serve the build using express
npm start
```
